pdfRag

A LangChain-native PDF question-answering pipeline with built-in guardrails.

🦜 End-to-end LangChain 🆓 Free models 🛡️ Guardrails in-pipeline

01Technologies used

Every stage of the pipeline is a LangChain component. Embeddings run locally; generation uses Groq's free tier.

🦜

Persistent Chroma vector store (cosine space) for fast similarity search with relevance scores.

cloud · free tier
🛡️

Custom guardrails

Plain-Python input / grounding / output checks — no external service, fully transparent.
free · in-repo

03The guardrails

Wired directly into the LCEL pipeline; any layer can stop the request and return a safe message.

🛡️ Input guard

Rejects empty / too-short / too-long questions and detects prompt-injection & jailbreak patterns (“ignore previous instructions”, “developer mode”, “reveal your system prompt”…).

🛡️ Grounding guard

If the best retrieved chunk scores below the relevance threshold, the pipeline refuses instead of letting the model hallucinate — and skips the LLM call entirely.

🛡️ Output guard

Redacts emails, phone numbers, SSNs and card-like numbers from the answer before it reaches the user.

🛡️ Prompt hardening

The system prompt confines the model to the retrieved context and treats that context as data, never as instructions — defense-in-depth against injection via the PDF.
